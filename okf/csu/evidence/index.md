# CSU Evidence Paths

How to trace CSU concepts to their underlying data, semantic models, and analysis patterns. Each evidence file maps a concept to its measurement systems, enabling navigation from "what is this?" to "what's the current status?" to "where can I investigate?"

## Operational Source Systems

* [MSX Dataverse (CRM)](msx-dataverse.md) — Authoritative for accounts, account plans, opportunities, milestones (pipeline + C2C)
* [MSX Insights (MSXi)](msxi.md) — Analytics layer: KPI measurements, snapshot metrics, actual outcomes (ACR, labour, pipeline rates, scorecards)
* [MDM & GRM](mdm-grm.md) — Authoritative for Unified contracts/packages (MDM) and CSA bookings/scheduling (GRM) — feeds delivery KPIs
* [eSXP CSP](esxp-csp.md) — Authoritative for Customer Success Plan lifecycle (priorities, RAID, milestone linkage) — causal signal for execution quality
