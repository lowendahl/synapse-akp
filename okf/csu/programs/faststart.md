# Definition

FastStart is an accelerated onboarding and deployment program that compresses time-to-value for new customer engagements. It provides structured, time-boxed delivery focused on getting customers to first meaningful value as quickly as possible.

# Key Characteristics

- Time-boxed delivery (typically 30–90 days)
- Structured deployment playbooks
- Dedicated resources for initial activation
- Clear handoff to BAU operations upon completion

# Relationship to MCEM

FastStart accelerates progression through [Stage 3 — Empower & Achieve](/mcem/stages/3-empower-and-achieve.md) by compressing the deployment-to-value timeline.
