# Design Philosophy

## Executive Summary
CSU-IQ is architected from first principles. Frameworks are implementation details; the architecture is the product.

## Core Philosophy
- Domain before technology.
- Declarative plans before execution.
- Explicit contracts over convention.
- Evolutionary architecture instead of big-bang redesigns.
- Human judgement remains central.

## Mental Model
Treat the platform as an enterprise reasoning engine rather than an AI chatbot.

## Trade-offs
Greater upfront design effort produces lower long-term complexity.

## Related ADRs
Clean Architecture, Planner/Runtime Separation, Tool Architecture.
