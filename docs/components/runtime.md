# AKP Runtime

## Purpose

Load, compose, and serve compiled knowledge packages.

## Responsibilities

- Package loading
- Signature verification
- Dependency resolution
- Graph initialization
- Retrieval initialization
- Authorization filtering
- Policy evaluation
- Caching
- Provenance return
- Query observability

## Out of Scope

- Planning
- Execution
- Business domain logic
- Knowledge authoring

## Promises

- Stable retrieval contract
- Governance enforcement
- Hybrid retrieval across vector, keyword, graph, and structured access

## Invariants

- Governance is never weakened through retrieval
- Provenance is always returned with results
- Packages are immutable once loaded
