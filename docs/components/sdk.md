# AKP SDK

## Purpose

Developer tooling for authoring, testing, and publishing knowledge packs.

## Responsibilities

- Project scaffolding
- Local compilation
- Knowledge tests
- Pack validation
- Publish workflow

## Out of Scope

- Runtime hosting
- Business applications

## Promises

- Fast feedback loop for authors
- Standard project structure
- Test-before-publish workflow

## Invariants

- The SDK always targets the stable AKP format version
- Tests run before publish
