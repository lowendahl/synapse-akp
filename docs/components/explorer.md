# Explorer

## Purpose

Interactive 3D visualization of compiled knowledge packs.

## Responsibilities

- Render compiled graph structures
- Display cross-pack relationships
- Support node inspection
- Support semantic navigation through the compiled graph

## Out of Scope

- Knowledge editing
- Compilation
- Runtime queries

## Promises

- Self-contained HTML artifact
- Offline operation
- Exact reflection of compiled package state

## Invariants

- Visualization matches the compiled pack state exactly
- No stale or regenerated data is shown
